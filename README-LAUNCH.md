# ZeusaberZ Testing — Launch Package

## Files
- `index.html` — production website
- `favicon.png` — standalone favicon
- `og-image.png` — social sharing preview
- `robots.txt` — crawler rules
- `sitemap.xml` — sitemap
- `README-LAUNCH.md` — launch notes

## Contact form
The form uses FormSubmit's AJAX endpoint and sends inquiries to:
`contact@zeusaberz.com`

The first submission may require a one-time email activation from FormSubmit.

## Recommended deployment
This is a static site and can be deployed directly to Netlify, Vercel, or Cloudflare Pages.

If using GitHub + Netlify/Vercel, deploy the contents of this folder with `index.html` as the entry point.
